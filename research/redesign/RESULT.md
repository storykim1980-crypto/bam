# 첨부 시안 기반 리디자인 완료

## 적용 범위
사용자가 제공한 code.html과 screen.png를 기준으로 차콜 배경, 골드 강조색, 사진 중심 카드, 섹션 순서와 여백을 재구성했습니다. 이번 시안을 새 기준으로 삼아 이전 밝은 테마를 교체했습니다. 시안의 외부 Tailwind·아이콘·폰트 CDN에 의존하지 않도록 로컬 CSS와 기존 이미지 자산으로 구현했습니다.

- 홈: 히어로 → 정보 안내 → 검색 → 신규 등록 → 업종 테마 → 업종별 매장 목록 → 방문 체크 → 지역 → 출처 노트 → 관심 매장 → 방문 준비 → 탐색 CTA.
- 공통: 데스크톱/모바일 내비게이션, 언어 전환, 푸터.
- 내부: 검색·업종·지역·상세·가이드·정책 화면에 같은 테마 적용.
- 실제 매장22곳(스낙크8/걸즈바7/릴랙세이션7), 기존 주소·요금·출처·검토일 유지. 이번 작업은 신규 영업 조사나 검토일 갱신이 아닙니다.

## 실제로 연결한 기능

1. **검색:** 매장명·업종·지역 조합을 실제22개 데이터에 연결했습니다. 지역만 지정했을 때 발생하던 검색 오류도 수정했습니다.
2. **홈 업종 탭:** 전체/스낙크/걸즈바/릴랙세이션 필터와 개수 표시, 초기6개에서 전체 목록 펼치기.
3. **관심 매장:** 카드 하트로 저장·해제, 동일 브라우저에서 새로고침 후 유지, 홈 관심 목록에서 상세 이동. 로그인·서버 저장·다른 기기 동기화 기능은 아닙니다.
4. **매장 상세:** 실제 주소·전화·지도·공식/SNS/예약 링크와 기존 요금·조건·출처 패널 유지. 링크를 통해 매장으로 이동하며 사이트가 예약을 대행하지 않습니다.
5. **모바일 메뉴:** 메뉴 열기·닫기·Escape 처리·하단 탐색.
6. **한·일·영:** 홈과 새 가이드, 내비게이션, 카드·필터를3언어에 연결했습니다. 언어 전환 시 검색 쿼리도 유지합니다.
7. **첫 방문 가이드:** 업종의 차이, 총액 확인, 출처·날짜, 매장 규칙, 릴랙세이션·예약 안내를 실제 운영 범위에 맞춰 새로 작성했습니다.

## 삭제·변경한 시안 요소

- ‘이주의 랭킹’ → ‘신규 등록 매장’. 실측 인기 순위를 주장하지 않습니다.
- ‘리얼 후기’ → ‘출처 검토 노트’. 가상 별점이나 체험담을 만들지 않았습니다.
- 100% 실사 검증, 만족도98.7%, 바가지0건 보장, 실시간 영업 레이더,24시간 상담 등의 근거 없는 문구·기능은 미사용.
- 공통 메뉴의 불필요한 광고·가격 계산기·랭킹 진입점을 정리했습니다. 과거 URL은 강제 삭제하지 않았습니다.
- 모든 매장이 동일한60분 총액·평점·특징 정보를 갖는 것처럼 보이던 검색 정렬·필터를 제거했습니다. 공개 요금 조건은 상세에서 확인하도록 연결합니다.
- 이미지에 AI 콘셉트 표시를 유지하며 실제 매장 사진으로 소개하지 않습니다.
