## 하단 바
사용자 화면의 `calc-bar#calcBar`, `calcBarPer`, `calcBarTotal`, ‘내역 보기’는 공개 GitHub Pages의 구버전 홈에서 확인했습니다. 현재 작업 소스에는 이미 없었습니다. 이번 버전은 이 상태를 전체 생성 HTML 검사와 브라우저 회귀 검사로 고정했습니다. 정상적인 모바일 5탭 내비게이션은 삭제하지 않았습니다. 홈 계산기 및 업종별 지역 요금 시세표 제거도 유지합니다. 전용 요금 페이지 계산기는 남아 있습니다.

`node qa/no-floating-total.mjs --static-only`를 배포 워크플로에 추가했습니다. 실제 GitHub Actions 원격 실행이나 공개 사이트 배포는 이번 작업에서 수행하지 않았습니다. 로컬 배포용 빌드만 검증했습니다.
