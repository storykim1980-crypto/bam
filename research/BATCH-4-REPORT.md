## 실제 방문에 중요한 처리
- BAR 2C: 기본 정보는20시, 요금표는19시부터라고 하여 차이를 표시했다. TAX15% 표기는 법정 세율로 해석하지 않고 내역 미확인으로 안내한다. K-POP 콘셉트만으로 한국어 응대를 보장하지 않는다.
- ARUE: 출처 자체의 사용자 제공 정보·정확성 미보장 고지를 반영했다. 자동연장·세금10%·서비스10% 별도 조건을 표시하고 계산 순서와 최종 총액은 추정하지 않았다.
- Re.Ra.Ku: 공식 상단의 평일 첫방문40분2,900엔 등 조건부 메뉴를 일반 상시요금이나 당사 할인권처럼 표시하지 않았다. 전체 일반 메뉴의 금액을 확인하지 못한 부분은 추정하지 않았다.
- 호구시 쇼쿠닌: 주소·전화·평일/주말 시간·요금·취소 조건을 수집했다. 2024년 공식 공지의 목요일 정기휴무와 얼리버드 종료를 별도로 반영하고 현재 계속 적용 여부는 확인 필요로 남겼다. 요금의 세금 포함 여부가 명확하지 않아 총액으로 확정하지 않았다.
- 후보 피타라비는 공개 연락처·상세 요금의 충분한 확인 없이 등록 건수를 늘리기 위해 게시하지 않았다.
- 사진·리뷰·인기 순위·홍보 문장·치료 효과·자격 보장은 복제하지 않았다. AI 업종 공통 보조 이미지와 바로 옆 고지 유지.

## 빠른 업데이트 도구 개선
`npm run research:export`로 게시 상태인 조사 매장만 CSV로 자동 출력한다. 기본 출력은 research/reports/venues.csv이며 `npm run research:export -- 파일경로.csv`로 위치를 지정할 수 있다.
- UTF-8 BOM, 쉼표·줄바꿈·따옴표 처리.
- 스프레드시트 수식으로 해석될 수 있는 접두어를 중립화함. 이 경우 앞에 작은따옴표가 붙을 수 있다.
- 임시·보관 상태의 매장은 제외하고 검증을 통과한 데이터만 출력.
- GitHub 배포 워크플로에도 CSV 출력 단계 추가. 이 변경 자체가 원격 업로드나 배포를 의미하지는 않는다.
