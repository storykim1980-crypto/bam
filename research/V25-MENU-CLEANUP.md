# v25 — 지역별 요금 시세 제거 및 메인 메뉴 재구성

## 적용 범위
- 스낙크/걸즈바/마사지 페이지에 지역별 시세표가 없는지 JA/KO/EN에서 확인.
- 재사용 컴포넌트의 지역별 요금 비교표·미니 시세표 생성 함수 제거. 메인에 남아 있던 미사용 가격 관련 코드·수입 구문 제거.
- 별도 요금 페이지에서도 전국 평균·지역 가격대·지역 배율 선택 UI 제거. 계산기는 전용 요금 페이지에만 유지하며 지역 가격 비교 기능은 없음.
- 메인 본문에는 요금 시뮬레이터와 계산기 안내 카드를 두지 않음.
- 메인 핵심 메뉴: 스낙크 / 걸즈바 / 마사지. 각 업종의 실제 목록 경로로 연결하는 내비게이션으로 구성.
- 메인 빠른 메뉴: 지역별 매장 찾기 / 처음 방문 가이드 / 매장명·조건 검색.
- 메인 업종 이미지는 이전에 독립 생성한 AI 참고 이미지로 연결. 실제 매장 사진이 아니라는 안내 유지.
- 각 업종의 방문 안내는 시뮬레이터 권유 대신 매장별 출처 요금·추가요금 확인 안내로 수정.
- 지역 페이지의 세금 포함 총액 비교 보장 문구를 매장별 공개 정보·출처 확인 안내로 정리.
- 매장별 실제 공개 요금 조건·출처·전화·지도는 유지. 조사22(스낙크10/걸즈바6/마사지6), 전체공개109로 변경 없음.
